One word for the boss who repeats your idea louder in the meeting as if it were his: **Echo**. `main.py` (Python 3, stdlib only) validates the word — exactly one word, 1–30 characters, no whitespace — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), chmod 0644, and reads it back to prove the file holds the word and nothing else.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
